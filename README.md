# 🏎️ SudAmerica Auto Elite

**Auto d'epoca, rally e supercar dal Paraguay verso Italia ed Europa.**

Sito web premium per la vendita di auto classiche, da rally e speciali trovate in Paraguay a prezzi competitivi, con servizio completo di ispezione, logistica e consegna a domicilio.

## 🌐 Visita il Sito

Il sito è pubblicato come GitHub Page: [**sudamericaautoelite.github.io**](#)

## 🎨 Design

- **Stile**: Modern & Bold con palette cyan / viola / arancio su sfondo scuro
- **Effetti**: Glassmorphism, scroll animations, 3D tilt sulle card, counter animati
- **Responsive**: Mobile-first, ottimizzato per smartphone, tablet e desktop
- **Tech**: HTML + CSS + JS puro — zero dipendenze esterne

## 📂 Struttura

```
├── index.html        # Pagina principale (one-page)
├── css/
│   └── style.css     # Design system e tutti gli stili
├── js/
│   └── main.js       # Interattività e animazioni
├── img/
│   ├── hero/         # Immagine hero
│   ├── cars/         # Foto delle auto
│   └── about/        # Foto showroom/team
└── README.md
```

## 🚗 Sezioni

1. **Hero** — Header full-screen con statistiche animate
2. **Catalogo** — Griglia di 10 auto con filtri per categoria
3. **Chi Siamo** — Missione, valori e competenze del team
4. **Come Funziona** — Timeline del processo in 5 step
5. **Contatti** — Form di contatto, info e social links
